# 吃點可愛的｜Pocket Bites

Cute mobile-first food-finder interactive prototype. Static HTML, CSS and JavaScript.

All in-page venues, menus, prices, opening labels and walking minutes are fictional demo data. Real search opens Google Maps; no live restaurant API or personal saved-list synchronization is connected.

Features: mood/keyword filters, budget including dine-in minimum, walking range, opening filter, local favorites, menu sheets, replacement, user-triggered GPS and real-map category search. GPS stays in memory and is only sent to Google when the user opens a map search. No private positions or saved lists are included in source.

Publish: GitHub Pages from main / root.

Edit the root HTML/CSS/JS files. Icons are a custom bun/location-pin SVG and PNG exports.
